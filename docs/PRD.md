# 微博备份工具 — 产品需求文档（PRD）

> 版本：v1.0 | 日期：2026-06-10 | 状态：Draft

---

## 1. 产品概述

### 1.1 产品定位

一款**本地运行的个人微博备份工具**。用户提供微博 Cookie 后，自动抓取全部微博内容并存到本地数据库，支持浏览、搜索和多格式导出。

**一句话描述**：把你的微博完整备份到本地，永久保存你的数字记忆。

### 1.2 核心价值

| 场景 | 痛点 | 解决方案 |
|------|------|----------|
| 注销微博账号前 | 内容会全部丢失 | 一键全量备份到本地 SQLite |
| 回忆翻看旧微博 | 微博翻页难、搜索烂、广告多 | 本地流畅浏览，秒级搜索 |
| 创作者维权 | 需要原创内容作证据 | 带时间戳的完整备份，JSON/HTML 导出 |
| 多账号管理 | 大小号内容分散 | 同一工具管理多个微博号 |
| 数据自主权 | 平台随时可能删帖/限流 | 数据完全在你自己的电脑上 |

### 1.3 产品形态

- **运行方式**：本地 Web 应用（`npm run dev`），浏览器打开 `localhost:3000`
- **数据存储**：SQLite 单文件，零配置
- **部署方式**：不上线公网，个人电脑本地运行
- **兼容性**：macOS / Windows / Linux，现代浏览器

## 2. 目标用户

### 2.1 用户画像

**主要用户**：有微博账号，希望备份自己微博内容的个人用户。

典型特征：
- 微博使用时间长（3 年以上），积累了数百至数千条微博
- 有一定的技术基础（能用终端、能理解 Cookie 是什么）
- 重视数据所有权，不希望内容只存在于平台上
- 可能管理多个微博账号（个人号 + 工作号 / 兴趣号）

### 2.2 用户故事

| 编号 | 用户故事 | 优先级 |
|------|----------|--------|
| US-01 | 作为用户，我希望能一键备份我所有的微博帖子 | P0 |
| US-02 | 作为用户，我希望能按时间浏览备份的微博 | P0 |
| US-03 | 作为用户，我希望备份数据能导出为通用格式（HTML/JSON）| P0 |
| US-04 | 作为用户，我希望能管理多个微博账号 | P1 |
| US-05 | 作为用户，我希望能增量同步（只抓新帖子）| P1 |
| US-06 | 作为用户，我希望能搜索备份的微博内容 | P1 |
| US-07 | 作为用户，我希望备份的微博图片也能存到本地 | P1 |
| US-08 | 作为用户，我希望能导出 Markdown 格式方便导入 Obsidian | P2 |
| US-09 | 作为用户，我希望能按时间范围、原创/转发筛选 | P2 |
| US-10 | 作为用户，我希望能导出 PDF / 打印成册 | P2 |
| US-11 | 作为用户，我希望能随机翻阅备份的微博，像翻旧相册一样 | P1 |

## 3. 功能需求

### 3.1 账号管理（P0）

#### FR-01：添加微博账号

- **输入**：微博 UID、SUB Cookie（可选：昵称手动标注）
- **验证**：点击「测试连接」按钮，用提供的 Cookie 请求 m.weibo.cn API，返回昵称和头像则连接成功
- **存储**：Cookie 加密存储（至少 base64 编码），避免明文暴露
- **规则**：同一个 UID 不能重复添加

#### FR-02：编辑账号

- 修改昵称、Cookie
- Cookie 更新后重置 `last_since_id`（强制全量同步）

#### FR-03：删除账号

- 删除账号时，关联的所有帖子、图片、同步日志一并删除
- **必须有二次确认弹窗**：显示将被删除的数据量，确认后执行

#### FR-04：账号列表

- 展示所有已添加账号
- 每个账号显示：昵称、UID、帖子总数、上次同步时间、Cookie 是否有效
- 排序：按添加时间倒序

---

### 3.2 微博同步（P0）

#### FR-05：开始同步

- 选择一个账号，点击「开始同步」
- **全量同步**：从第一条微博开始抓取（首次同步或 Cookie 更新后）
- **增量同步**：从上一次 `last_since_id` 继续（常规同步）
- 同步过程中：实时显示进度（已抓取页数、新增帖子数）

#### FR-06：同步进度

实时展示：
- 当前状态文字（"正在获取第 N 页..."）
- 进度百分比（基于页面数估算）
- 已抓取总数 / 新增数
- 预估剩余时间

#### FR-07：取消同步

- 同步过程中可点击「取消」
- 已入库的帖子保留，下次从断点续传

#### FR-08：同步日志

- 每次同步记录：账号、开始时间、结束时间、耗时、抓取数、新增数、状态
- 按时间倒序展示，最近 50 条

#### FR-09：Cookie 状态检测

- 同步开始前自动检测 Cookie 是否有效
- Cookie 过期 → 显示错误提示，引导用户重新获取

---

### 3.3 帖子浏览（P0）

#### FR-10：时间线展示

- 按发布时间倒序排列
- 每 20 条一页

#### FR-11：帖子卡片

每个帖子卡片展示：

| 信息 | 说明 |
|------|------|
| 发布时间 | 格式：`2024年3月15日 14:30` |
| 发布账号 | 头像 + 昵称（多账号场景） |
| 正文内容 | 完整文本，保留换行和表情符号 |
| 图片 | 水平滚动缩略图，点击可查看大图 |
| 客户端来源 | `来自 iPhone 客户端` |
| 互动数据 | 转发数、评论数、点赞数 |
| 标签 | 原创/转发、长文 |

#### FR-12：转发帖子展示

- 转发帖显示「转发了 @xxx」
- 转发内容折叠显示
- 点击「展开原文」查看被转发帖子的完整内容

#### FR-13：筛选

| 筛选项 | 类型 | 说明 |
|--------|------|------|
| 账号 | 下拉选择 | 全部 / 指定账号 |
| 类型 | 分段控制 | 全部 / 仅原创 / 仅转发 |
| 日期范围 | 双日期选择器 | 起止日期 |
| 关键词 | 文本输入 | 全文搜索，300ms 防抖 |

#### FR-14：搜索

- 全文模糊搜索（LIKE 匹配）
- 搜索范围：帖子正文
- 结果按时间倒序排列

---

### 3.4 数据导出（P0）

#### FR-15：JSON 导出

- 导出当前筛选范围内的帖子
- JSON 结构：`{ exported_at, total, account, posts: [...] }`
- 包含完整字段：正文、时间、互动数据、原始 JSON、图片 URL

#### FR-16：HTML 导出

- 独立 HTML 文件，内嵌 CSS 样式
- 与浏览页相同的卡片布局
- 可分账号导出
- 可离线直接浏览器打开

#### FR-17：Markdown 导出（ZIP）

- 打包为 ZIP 文件
- 每篇帖子一个 .md 文件
- 文件命名：`YYYY-MM-DD_HHmm_weibo_id.md`
- Frontmatter：date, weibo_id, uid, is_original, source
- 可直接导入 Obsidian

#### FR-18：PDF / 打印

- 生成打印优化页面（隐藏导航栏和过滤栏）
- 调用浏览器 `window.print()`
- 用户选择「另存为 PDF」保存

---

### 3.5 图片备份（P1）

#### FR-19：图片存储

- 图片下载到 `public/uploads/weibo/`
- 文件命名：`<weibo_id>_<序号>.<ext>`
- 通过本地 URL `/uploads/weibo/<filename>` 访问

#### FR-20：批量下载

- 同步完成后，后台批量下载未下载的图片
- 下载进度展示
- 失败的图片标记为「下载失败」，可重试

---

### 3.6 随机刷（P1）

#### FR-21：随机浏览模式

- 从导航栏进入「随机刷」模式
- 双列瀑布流布局（类似小红书），随机排列帖子
- 每条帖子以卡片形式展示：图片优先（有图则图片占主视觉），文字截断预览
- 下拉自动加载更多随机帖子（每次加载 10-20 条）
- 点击卡片可查看帖子详情（弹窗或跳转）
- 顶部显示：「随机浏览中 · 已看 67 条」

#### FR-22：随机刷筛选

- 顶部固定筛选栏（可折叠）：
  - 账号：指定账号 / 全部
  - 日期范围：限定时间段
  - 类型：仅原创 / 仅转发 / 全部
- 筛选变更后刷新整个列表

#### FR-23：随机刷交互

- **换一批**：顶部「🔀 换一批」按钮，一键刷新全部卡片
- **下拉加载**：滚动到底部自动追加新的随机帖子
- **点击卡片**：弹出详情弹窗，完整展示帖子内容、图片、互动数据
- **转发帖**：卡片上标记「转发」角标，弹窗中可展开原帖
- **回到顶部**：浮动按钮，快速回到顶部并刷新
- **退出随机模式**：点击导航栏其他标签即退出

## 4. 用户流程

### 4.1 首次使用流程

```
打开应用（localhost:3000）
    │
    ▼
[空状态提示] → 引导去添加账号
    │
    ▼
添加账号 (/accounts)
  ├─ 输入 UID
  ├─ 在浏览器中登录微博 → 从 DevTools 复制 SUB Cookie
  ├─ 粘贴 Cookie
  ├─ 点击「测试连接」→ 成功显示昵称 ✅
  └─ 保存
    │
    ▼
开始同步 (/sync)
  ├─ 选择刚添加的账号
  ├─ 点击「开始同步」
  ├─ 等待同步完成（视微博数量，可能几分钟到几十分钟）
  └─ 同步完成 ✅
    │
    ▼
浏览帖子 (/posts)
  └─ 看到所有备份的微博，时间倒序排列 🎉
```

### 4.2 日常增量同步流程

```
打开应用
    │
    ▼
同步页 → 选择账号 → 开始同步
    │
    ▼
仅抓取新帖子（since_id 增量）
    │
    ▼
完成 → 回到浏览页查看新内容
```

### 4.3 Cookie 更新流程

```
Cookie 过期提示
    │
    ▼
账号管理 → 编辑账号 → 粘贴新 Cookie
    │
    ▼
测试连接 → 成功 → 保存
    │
    ▼
自动重置 since_id（下次同步会全量抓取）
```

**卡片布局规则**：
- 图片帖：图片占卡片高度 60-70%，底部文字截断 2-3 行
- 纯文字帖：大字号文字为主体，背景微妙渐变（类似微博轻帖风格）
- 转发帖：左上角小角标「转发」
- 长文帖：角标「长文」，文字截断 4 行
- 卡片高度不固定，瀑布流自然排列

## 7. 技术方案

### 7.1 技术栈

| 维度 | 选择 | 说明 |
|------|------|------|
| 框架 | Next.js 16 App Router | React 19 + TypeScript |
| 样式 | TailwindCSS v4 + CSS 变量 | 复用 Design V2 设计令牌 |
| 数据库 | SQLite (via @libsql/client) | 本地单文件，零配置 |
| 数据抓取 | Node.js fetch() | 调用 m.weibo.cn 移动端 API |
| 导出打包 | JSZip | Markdown ZIP 导出 |
| 运行方式 | `npm run dev` | 本地运行，不上线 |

### 7.2 微博数据抓取原理

```
用户浏览器登录 weibo.com
        │
        ▼
从 DevTools 复制 SUB Cookie
        │
        ▼
粘贴到本工具 → 工具用 Cookie 调用 m.weibo.cn API
        │
        ▼
GET /api/container/getIndex?containerid=107603<UID>&since_id=...
        │
        ▼
返回 JSON → 解析卡片 → 入库 SQLite
        │
        ▼
翻页：从响应的 cardlistInfo.since_id 获取下一页游标
        │
        ▼
终止：响应中不再包含 since_id → 全部抓取完成
```

- 每页约 20 条帖子
- 请求间隔 1.5 秒（避免封 IP）
- 最多重试 3 次
- 长文自动展开（调用 `/statuses/extend` 端点）

### 7.3 Cookie 安全说明

- Cookie 存储在本地 SQLite 中
- 数据库文件在用户自己的电脑上
- 不上传到任何服务器
- 不在日志中记录 Cookie 内容
- 导出时不包含 Cookie

### 7.4 性能预估

| 微博数量 | 预计同步时间 |
|----------|-------------|
| 100 条 | ~10 秒 |
| 1,000 条 | ~1.5 分钟 |
| 5,000 条 | ~7 分钟 |
| 10,000 条 | ~15 分钟 |

## 附录 A：Cookie 获取指南

### 步骤

1. 在 Chrome 浏览器中打开 [weibo.com](https://weibo.com) 并登录
2. 按 `F12` 打开开发者工具
3. 点击顶部 `Application`（应用程序）标签
4. 左侧菜单：`Storage` → `Cookies` → `https://weibo.com`
5. 在列表中找 `SUB`，双击值（Value）列，`Ctrl+C` 复制
6. 粘贴到本工具的 Cookie 输入框

### 注意事项

- Cookie 有效期数小时至数天，过期后需重新获取
- 不要把你的 Cookie 分享给任何人
- 本工具仅用 Cookie 调用微博 API 抓取数据，不会用于其他目的
