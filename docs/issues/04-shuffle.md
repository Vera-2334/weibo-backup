# Issue 04：双列随机刷

**优先级**：P1 | **类型**：AFK | **阻塞**：Issue 03

## 目标

双列瀑布流随机浏览页面（类似小红书）。从数据库随机抽取帖子，图片优先卡片布局，换一批、下拉加载、点击详情弹窗。

## 用户故事

- US-11：作为用户，我希望能随机翻阅备份的微博，像翻旧相册一样

## 验收标准

- [ ] 双列瀑布流布局，图片帖/纯文字帖/转发帖不同卡片样式
- [ ] 图片帖：图片占卡片 60-70%，底部文字截断 2-3 行
- [ ] 纯文字帖：大字号文字 + 微妙渐变背景
- [ ] 转发帖：左上角「转发」角标
- [ ] 长文帖：「长文」角标
- [ ] 顶部「🔀 换一批」按钮，一键刷新全部卡片
- [ ] 下拉滚动自动追加新卡片（每次 10-20 条）
- [ ] 进度显示：随机浏览中 · 已看 N 条
- [ ] 点击卡片弹出详情弹窗（完整内容 + 大图）
- [ ] 弹窗内可 ← 上一条 / 下一条 → 连续浏览
- [ ] 支持按账号、日期范围、类型筛选随机范围
- [ ] 筛选变更后刷新列表

## 技术要点

- SQLite `ORDER BY RANDOM()` 实现随机抽取
- CSS columns 或 CSS Grid 实现瀑布流
- 弹窗使用 Portal 或 Dialog
