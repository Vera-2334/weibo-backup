# Issue 03：帖子时间线浏览 + 筛选搜索

**优先级**：P0 | **类型**：AFK | **阻塞**：Issue 02

## 目标

帖子时间线浏览页面。按年份分组，支持日期筛选、关键词搜索、原创/转发切换。完整的帖子卡片 UI（匹配 demo.html 的设计）。

## 用户故事

- US-02：作为用户，我希望能按时间浏览备份的微博
- US-06：作为用户，我希望能搜索备份的微博内容
- US-09：作为用户，我希望能按时间范围、原创/转发筛选

## 验收标准

- [ ] 帖子按发布时间倒序排列，按年份分组（年份分隔线）
- [ ] 每页 20 条，底部「加载更多」
- [ ] 日期范围筛选：两个 `<input type="date">` 选择起止日期
- [ ] 关键词搜索：正文模糊匹配，300ms 防抖
- [ ] 原创/转发/全部切换（分段控制器）
- [ ] 转发帖折叠显示「转发了 @xxx」，点击展开原文
- [ ] 长文帖标记「长文」角标
- [ ] 图片横向滚动展示缩略图
- [ ] 帖子卡片：发布时间、正文、图片、客户端来源、互动数据
- [ ] 统计栏：共 N 条微博、账号数、时间范围
- [ ] 筛选变更后结果显示更新
