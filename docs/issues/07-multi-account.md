# Issue 07：多账号管理

**优先级**：P1 | **类型**：AFK | **阻塞**：Issue 02

## 目标

完善多账号体验。账号列表管理、同步页账号选择、浏览页账号筛选、跨账号统计。

## 用户故事

- US-04：作为用户，我希望能管理多个微博账号

## 验收标准

- [ ] 账号页展示所有已添加账号卡片（昵称、UID、帖子数、上次同步时间、Cookie 状态）
- [ ] 编辑账号：修改昵称或 Cookie，Cookie 更新后重置 since_id
- [ ] 删除账号：二次确认弹窗，显示将被删除的数据量，确认后级联删除所有关联帖子/图片/日志
- [ ] 同步页：下拉选择要同步的账号
- [ ] 浏览页：下拉按账号筛选帖子
- [ ] 随机刷：下拉按账号筛选随机范围
- [ ] 统计栏：多账号时显示「来自 N 个账号」
- [ ] 每个帖子卡片上显示所属账号标签（昵称 + 头像色）
